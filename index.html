はじめての GITHUB

GitHubをはじめよう

ファイルを共有して、変更の履歴を残す。
GitHubは、チームでも一人でも使える開発の場所です。

変更を記録できる

いつ・誰が・何を変えたかを確認でき、以前の内容もたどれます。

ファイルを共有できる

コードや資料をリポジトリにまとめ、メンバーと共有できます。

一緒に改善できる

変更案を見せ合い、レビューや相談をしながら作業を進められます。

タイトルを変えて、履歴を残してみよう。

このページの見出しを変えるだけで、変更の記録を体験できます。

  1. ファイルを編集index.html の <h1> を「GitHubで履歴を残そう」に変えて保存。
  2. コミットで記録差分を確認し、「タイトルを変更」とメッセージを付けてコミット。
  3. GitHubへ送るプッシュして共有。GitHubのコミット履歴から、変更前後を確認。

ファイルの保存だけでは、Gitの履歴には残りません。コミットは変更の記録、プッシュはその記録をGitHubへ送る操作です。

Gitは変更履歴を管理する仕組み。GitHubは、そのリポジトリをオンラインで共有・管理するサービスです。
